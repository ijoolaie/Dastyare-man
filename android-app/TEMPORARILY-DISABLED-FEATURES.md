# قابلیت‌های موقتاً غیرفعال‌شده — بازگردانی الزامی

این فایل یادداشت پیگیری دائمی مخزن است. هیچ‌یک از قابلیت‌های زیر حذف دائمی نشده‌اند و باید پس از حل مسیر توزیع و بررسی امنیتی، دوباره فعال و روی دستگاه واقعی آزمایش شوند.

## موارد معلق

- [ ] **خواندن صندوق پیامک (sms_read)**
  - مجوز READ_SMS از AndroidManifest.xml موقتاً برداشته شده است.
  - دستور در Commands.smsRead پیام روشنِ غیرفعال‌بودن برمی‌گرداند.
  - پیاده‌سازی قبلی در همان تابع به‌صورت کامنت حفظ شده است.
  - بازگردانی: افزودن مجوز به Manifest، فعال‌سازی دوباره پیاده‌سازی و درخواست runtime فقط هنگام نیاز؛ سپس بررسی الزامات سیاستی و مسیر توزیع.

- [x] **خواندن اعلان‌های سایر برنامه‌ها (notifications)**\n  - سرویس NotificationListener در Manifest ثبت شده است.\n  - کاربر باید دسترسی Notification access را از منوی تنظیمات اپ به‌صورت دستی فعال کند.\n  - دستور `notifications` پس از اعطای دسترسی، اعلان‌های اخیر را برمی‌گرداند.\n\n- [ ] **ارسال خودکار پیامک (sms_send)**
  - مجوز SEND_SMS موقتاً از Manifest برداشته شده است.
  - قابلیت فعلی حذف نشده؛ برنامه پیامک را با شماره و متن آماده باز می‌کند و کاربر ارسال نهایی را تأیید می‌کند.
  - بازگردانی ارسال خودکار: پس از بررسی مسیر مجاز توزیع، مجوز را اضافه کن و پیاده‌سازی SmsManager را از تاریخچه Git بازیابی کن؛ درخواست مجوز باید فقط هنگام نیاز باشد.

## معیار بستن این یادداشت

این موارد فقط وقتی تکمیل محسوب می‌شوند که:
1. مسیر توزیع و الزامات سیاستی/امنیتی برای قابلیت‌های باقی‌مانده روشن شده باشد.
2. قابلیت در کد و Manifest بازگردانی شده باشد.
3. ساخت موفق و تست واقعی روی دستگاه انجام شده باشد.
4. کاربر عملکرد دوباره فعال‌شده را تأیید کرده باشد.

**هشدار برای توسعه‌های بعدی:** فایل NotificationListener.kt، منطق smsRead و تاریخچه smsSend را حذف نکن. این قابلیت‌ها تا زمان بازگردانی باید حفظ شوند.

> Update for the current bridge build: `sms_send` is now available. It opens the SMS composer by default. Direct send is supported only with `confirm: true` and after the user grants Android's SEND_SMS permission. `sms_read` remains disabled. See `README.md` for the `screen`, `contacts`, `call`, and `sms_send` command arguments.
