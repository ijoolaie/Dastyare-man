# دستیار من — اپ اندروید (پل دستگاه) 📱

این اپ، گوشی اندروید تو را به «دستیار من» وصل می‌کند تا هوش مصنوعی بتواند
گوشیت را مدیریت کند: مخاطبین، تماس، اپ‌ها، موزیک، صدای گوشی، چراغ‌قوه، ویبره، اعلان، موقعیت مکانی و اطلاعات سیستم.

> **محدودیت نسخه نصب مستقیم:** خواندن صندوق پیامک غیرفعال است. خواندن اعلان‌های برنامه‌های دیگر با فعال‌کردن دستی دسترسی Notification access در تنظیمات اندروید قابل استفاده است. ارسال پیامک با بازکردن برنامه پیامک و تأیید نهایی کاربر انجام می‌شود.

- بدون root — فقط مجوزهای استاندارد اندروید
- Foreground Service — همیشه در پس‌زمینه زنده می‌ماند
- بعد از اتصال، خودِ اپ «دستیار من» را داخل WebView نشان می‌دهد

---

## گام ۱ — ساخت APK در ویندوز (روش ساده)

1. پیش‌نیازها را طبق فایل [`BUILD-APK.md`](BUILD-APK.md) فقط یک‌بار نصب کن: JDK 17 یا 21 و Android SDK Platform 34 و Build Tools 34.0.0.
2. روی `build-apk.bat` دوبار کلیک کن؛ یا در PowerShell دستور `.\build-apk.bat` را اجرا کن.
3. اسکریپت در صورت نیاز Gradle 8.7 را به‌صورت محلی دانلود می‌کند و APK را می‌سازد.
4. خروجی در `dist\dastyar-debug.apk` قرار می‌گیرد.

برای جزئیات نصب SDK و رفع خطاها، فایل `BUILD-APK.md` را ببین. Android Studio و نصب سراسری Gradle لازم نیست.

برای ساخت Release آزمایشی: `.\build-apk.bat -BuildType release`؛ این خروجی هنوز با کلید اختصاصی انتشار امضا نشده است.

## گام ۲ — نصب

1. فایل `dist\dastyar-debug.apk` را به گوشی منتقل و باز کن.
2. اگر پرسید «نصب از منابع ناشناس»، برای مرورگر/فایل‌منیجر اجازه بده.
3. APK نصب‌شده **امضای debug** دارد — برای استفاده شخصی کاملاً کافی است.

## گام ۳ — اتصال (جفت‌سازی)

1. در اپ وب «دستیار من» برو به: **جعبه‌ابزار › تب دستگاه‌ها › افزودن دستگاه جدید**
2. گزینه **«اپ اندروید»** را انتخاب کن، اسم دستگاه را بنویس و «ساخت دستگاه و توکن» را بزن.
3. **آدرس سرور** و **توکن** نمایش‌داده‌شده را کپی کن.
4. اپ اندروید را باز کن — آدرس سرور از قبل پر است؛ فقط **توکن** را وارد و «اتصال» را بزن.
5. تمام! اپ حالا صفحه اصلی «دستیار من» را نشان می‌دهد و پل در پس‌زمینه فعالی است.

## گام ۴ — مجوزها (در زمان نیاز)

اپ هنگام نصب یا اولین اجرا هیچ مجوز حساس runtime را یک‌جا درخواست نمی‌کند.
هر مجوز فقط وقتی یکی از قابلیت‌های وابسته به آن اجرا شود درخواست خواهد شد:

| مجوز | زمان درخواست |
| --- | --- |
| SMS read | موقتاً غیرفعال در نسخه نصب مستقیم؛ جزئیات در فایل پیگیری |
| SMS send | بازکردن برنامه پیامک؛ کاربر ارسال نهایی را تأیید می‌کند |
| Contacts | هنگام جستجوی مخاطبین |
| Location | هنگام درخواست موقعیت مکانی |
| Notifications (اندروید ۱۳+) | هنگام ارسال اعلان از طرف دستیار |
| Phone | برای تماس مستقیم لازم نیست؛ بدون آن صفحه شماره‌گیری باز می‌شود |

اگر اپ در پس‌زمینه باشد، درخواست ثبت می‌شود و هنگام بازکردن اپ نمایش داده خواهد شد.
پس از تأیید مجوز، دستور را دوباره اجرا کن. ردکردن مجوز مانع استفاده از سایر قابلیت‌های برنامه نمی‌شود.

تنظیمات بهینه‌سازی باتری از منوی ⚙️ اپ قابل دسترسی است. برای خواندن اعلان‌های سایر برنامه‌ها، دسترسی Notification access را از منوی تنظیمات اپ فعال کن.

## عملیات‌های پشتیبانی‌شده

| عملیات | توضیح |
| --- | --- |
| `sysinfo` / `device_status` / `battery` | مشخصات، وضعیت شبکه، زنگ، روشنایی، باتری، رم و حافظه |
| `notify` | نمایش اعلان روی گوشی |
| `vibrate` | ویبره با مدت مشخص |
| `open_url` / `open_app` / `apps` | باز کردن لینک/اپ، فهرست اپ‌ها |
| `notifications` | خواندن اعلان‌های اخیر پس از فعال‌سازی دستی Notification access |
| `media` / `volume` / `ringer` | کنترل پخش، صدا و حالت زنگ (عادی/لرزش/بی‌صدا) |
| `brightness` | خواندن و تنظیم روشنایی صفحه؛ برای تغییر، مجوز Modify system settings لازم است |
| `flashlight` | روشن/خاموش چراغ‌قوه |
| `geolocation` | آخرین موقعیت GPS |
| `sms_send` | بازکردن برنامه پیامک با شماره و متن آماده؛ ارسال با تأیید کاربر |
| `sms_read` | غیرفعال در نسخه نصب مستقیم |
| `contacts` / `call` | مخاطبین و تماس (نیازمند تأیید کاربر در چت) |

## نکته‌ها

- عملیات‌های حساس (پیامک، مخاطبین، تماس) سمت سرور هم گیت تأیید دارند؛
  دستیار اول از تو اجازه می‌گیرد بعد اجرا می‌کند.
- خواندن کلیپ‌بورد از پس‌زمینه در اندروید ۱۰+ توسط سیستم محدود شده — این
  محدودیت همه اپ‌ها دارد، نه مخصوص این اپ.
- اگر اپ کشته شد: بهینه‌سازی باتری را غیرفعال کن و یک‌بار اپ را باز کن؛
  بعد از ری‌استارت گوشی هم سرویس خودکار بالا می‌آید.
- سرور و توکن فقط در حافظه محلی خود گوشی ذخیره می‌شوند.

## ساختار پروژه

```
android-app/
├── settings.gradle
├── build.gradle
├── gradle.properties
└── app/
    ├── build.gradle
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/ir/dastyar/bridge/
        │   ├── MainActivity.kt        # جفت‌سازی + WebView
        │   ├── BridgeService.kt       # سرویس اتصال پس‌زمینه، retry و وضعیت اتصال
        │   ├── Commands.kt            # ۱۸ عملیات اندروید
        │   ├── NotificationListener.kt# خواندن نوتیفیکیشن‌ها
        │   ├── BootReceiver.kt        # شروع خودکار بعد از بوت
        │   └── Prefs.kt               # ذخیره اتصال
        └── res/                       # رابط فارسی RTL
```
